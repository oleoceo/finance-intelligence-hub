## Implementation Sequence

1. **Inventory existing test infrastructure**:
 - Review `vitest.workspace.ts` for completeness
 - Review `vitest.integration.config.ts` for clarity
 - Check all package-level `package.json` files for test scripts
 - Verify Testcontainers usage in integration tests

2. **Define coherent test separation**:
 - Unit tests: `packages/*/src/**/*.test.ts` (no database, no external services)
 - Application/API tests: `apps/api/src/**/*.test.ts` (may use mocked dependencies)
 - PostgreSQL integration tests: `tests/integration/**/*.test.ts` (real PostgreSQL via Testcontainers)

3. **Ensure stable root commands**:
 - Verify `pnpm test` runs all unit tests across packages
 - Verify `pnpm test:integration:postgres` runs PostgreSQL integration tests
 - Add any missing root-level scripts for convenience (e.g., `test:unit`, `test:all`)

4. **Configure deterministic test discovery**:
 - Ensure include/exclude patterns are consistent across configs
 - Verify `dist/**` is excluded everywhere
 - Verify `node_modules/**` is excluded everywhere

5. **Ensure isolation between test types**:
 - Unit tests should not require PostgreSQL or Testcontainers
 - Integration tests should use isolated PostgreSQL containers
 - Verify no cross-contamination between test suites

6. **Document Testcontainers lifecycle**:
 - Ensure containers start and stop cleanly
 - Document cleanup expectations
 - Verify no leftover containers after test runs

7. **Add Production guard**:
 - Ensure tests abort if they detect `finance_hub_prod` configuration
 - Document this guard for future tasks

8. **Verify reliable failure exit codes**:
 - Tests should exit with non-zero code on failure
 - CI must be able to detect test failures reliably

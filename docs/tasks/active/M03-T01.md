## Behavior and ownership

- Pure name/pattern normalization: trim, lowercase, collapse consecutive whitespace; deterministic/idempotent; preserve raw input separately. Domain §250 requires raw preservation; the simple algorithm is a bounded planning choice. No accent stripping or sender/tax identity normalization.
- Books/Accounts/Categories/Merchants share active/archived_at consistency. Inject server time; repeated archive preserves its timestamp. Rules/Senders have active only. Do not apply normalized-name utilities to entities without such a column.
- Pure guards receive dependency/usage facts: Book currency immutable after Accounts/Transactions; Account Book immutable after creation; Account currency/type immutable after financial use. Distinguish a changed value from a no-op.
- Shared errors expose safe reasons/fields, without SQL or HTTP types. No required abstract base-use-case class; use explicit use cases and extract only demonstrated duplication.
- Core owns repository, read and transaction interfaces under src/application/ports. Initial contracts include Book/Account lookup, FinancialUsageReader, SenderDefaultReferenceReader and transaction-scoped ordered configuration locks/readers/repositories. Never expose a Kysely transaction to Core.
- FinancialUsageReader: hasBookUsage(bookId), hasAccountUsage(accountId). SenderDefaultReferenceReader: hasBookDefault(bookId), hasAccountDefault(accountId), including inactive senders. T02 implements working Database adapters; no permissive placeholder.
- T03/T04 add their entity-specific Core repository ports. Avoid generic CRUD/universal findByName uniqueness abstractions; Merchant lookups may return multiple rows.

## Concurrency and layering

Define the overview's deterministic lock order and re-read/retry contract. Database owns commit/rollback/connection mechanics; Core owns use-case policy. Core cannot import Database, pg, Kysely or Fastify. T02 implements the shared transaction adapter; T03 can extend its Category capabilities. Plain transactional read-check-write is not a race guarantee.

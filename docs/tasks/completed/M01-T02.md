Establish the TypeScript/pnpm workspace and engineering baseline for the Finance Intelligence Hub.

This task creates the foundational repository structure, configuration files, and tooling scaffolding required for subsequent implementation tasks.

Do not implement any business logic, database connections, or financial domain functionality.

## 5. Implementation requirements

### 5.1 Root package.json

Create a root `package.json` that:

- defines the project name and version;
- sets `"type": "module"` for ESM;
- includes workspace references to `apps/*` and `packages/*`;
- defines scripts for:
  - `build`: builds all workspace packages/apps;
  - `typecheck`: runs TypeScript type checking across workspace;
  - `lint`: runs ESLint across workspace;
  - `format:check`: checks formatting with Prettier;
  - `format`: formats code with Prettier;
  - `test`: runs Vitest tests across workspace.

### 5.2 pnpm-workspace.yaml

Create `pnpm-workspace.yaml` defining:

- `packages:` array including `apps/*` and `packages/*`.

### 5.3 TypeScript configuration

Create:

- `tsconfig.base.json`: base configuration with:
  - `"strict": true`;
  - `"module": "NodeNext"` or `"ESNext"`;
  - `"moduleResolution": "NodeNext"` or `"Bundler"`;
  - `"target": "ES2022"` or later;
  - `"esModuleInterop": true`;
  - `"skipLibCheck": true`;
  - `"declaration": true`;
  - `"declarationMap": true`;
  - `"sourceMap": true`;
  - `"outDir": "./dist"`;
  - `"rootDir": "./src"`.

- `tsconfig.json` at root referencing `tsconfig.base.json` via `"extends"`.

- Per-package `tsconfig.json` files in:
  - `apps/api/tsconfig.json`
  - `packages/core/tsconfig.json`
  - `packages/database/tsconfig.json`

  Each extending `../../tsconfig.base.json` (adjust paths as needed) and setting their own `compilerOptions.outDir` and `include` patterns.

### 5.4 Workspace directories

Create the following directory structure with minimal `package.json` and `tsconfig.json` in each:

```
apps/
  api/
    src/
      index.ts (minimal export or placeholder)
    package.json
    tsconfig.json
packages/
  core/
    src/
      index.ts (minimal export or placeholder)
    package.json
    tsconfig.json
  database/
    src/
      index.ts (minimal export or placeholder)
    package.json
    tsconfig.json
```

Each package `package.json` should:

- have a unique name (e.g., `@finance-hub/api`, `@finance-hub/core`, `@finance-hub/database`);
- set `"type": "module"`;
- define `"main"` and `"types"` fields pointing to dist output;
- include a `"scripts"` section with at least `build` and `typecheck`.

### 5.5 ESLint configuration

Create `.eslintrc.json` or `eslint.config.js` (prefer flat config if using ESLint v9+) with:

- TypeScript parser (`@typescript-eslint/parser`);
- Recommended TypeScript rules;
- Rules enforcing strict mode practices.

Note: Do not install packages yet. Only create the configuration file structure.

### 5.6 Prettier configuration

Create `.prettierrc` with sensible defaults:

- `semi: true`
- `singleQuote: true`
- `trailingComma: "all"`
- `tabWidth: 2`
- `printWidth: 100`

Create `.prettierignore` excluding:

- `node_modules/`
- `dist/`
- `*.log`

### 5.7 .env.example

Create `.env.example` with placeholder entries for:

- `NODE_ENV=development`
- `DATABASE_URL=` (empty, no real credentials)
- `LOG_LEVEL=info`

Do not include any real secrets or credentials.

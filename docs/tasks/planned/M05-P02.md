# M05-P02 — Deterministic interpretation

**Status:** PROPOSED / NOT AUTHORIZED. **Prerequisites:** accepted review and P01 accepted interfaces. **Closure:** Draft PR and exact-head CI GREEN → REVIEW REQUIRED; DONE only after human acceptance.

## Objective and ownership

Build a pure Core interpretation model that parses one authorized message into at most one candidate `CreateTransactionInput` or a typed unknown/ambiguous/confirmation outcome. P02 extracts explicit user values; P03 resolves omitted references and defaults. No AI provider is required.

**Permitted paths:** `packages/core/src/domain/inbox/**`, `packages/core/src/application/inbox/interpret-message.ts`, `packages/core/src/application/ports/interpretation-ports.ts`, `packages/core/src/index.ts`, corresponding Core `*.test.ts`. P02 may define Interpretation record/attempt interfaces; PostgreSQL persistence of attempts belongs to P05 composition using P01 transaction facilities.

**Dependencies/interfaces:** consume P01 normalized authorized message type and M04 `CreateTransactionInput`, Money/date validators via `@finance-hub/core` internal modules. Return explicit extracted values with provenance so P03 cannot overwrite them. P05 persists `interpretations` by `(inbox_message_id, attempt_number)`.

## Acceptance

- Deterministic grammar covers accepted V0.1 Expense, Income, Transfer examples; no external AI call. One message produces at most one command. Multiple commands, unsupported intent, missing required data and ambiguous values never post silently; return typed clarification/confirmation or safe failure.
- Explicit amount, Book, Account, Category, Merchant, date and transaction type outrank inference. Preserve M04 decimal-string Money, positive amount, Book timezone date, currency and transfer constraints; parser cannot introduce float money, `occurred_at`, FX, cross-Book or refund as a generic type.
- Contextual short replies (`sim`, `não`, `1`, `2`) are identified as reply candidates for P04, not standalone financial creates. Edited/deleted message content does not mutate earlier Transactions.

**Required tests:** unit matrix for deterministic variations, explicit precedence, malformed/ambiguous/multiple commands, reply tokens, exact Money/date inputs and no AI configuration. No PostgreSQL test is required for this pure slice; P05/P06 own real PostgreSQL Interpretation persistence and full pipeline tests. Retain all M04 tests.

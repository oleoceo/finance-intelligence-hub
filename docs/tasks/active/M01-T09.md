## Objective

Establish the minimum continuous-integration baseline required by the frozen M01 roadmap. This task creates a CI pipeline that verifies the established baseline (dependency install, lint, format check, typecheck, build, unit tests, PostgreSQL integration tests, migration-from-empty-database verification) using Node 24.x and pinned pnpm 12.3.4. It does NOT add deployment/CD, push images, access VPS, or use Production credentials.

## Implementation Sequence

1. **Determine repository provider**:
 - Check remote URL to confirm GitHub hosting
 - If GitHub, proceed with GitHub Actions
 - If different provider, adapt accordingly (but GitHub Actions is preferred for repository-native CI)

2. **Create CI workflow structure**:
 ```
 .github/workflows/
 └── ci.yml
 ```

3. **Define CI pipeline steps** (consume stable commands from T07/T08):
 - Checkout code
 - Setup Node.js 24.x
 - Setup pnpm 12.3.4
 - Install dependencies with frozen lockfile: `pnpm install --frozen-lockfile`
 - Run lint
 - Run format check
 - Run typecheck
 - Run build
 - Run unit tests (`pnpm test`)
 - Run PostgreSQL integration tests (`pnpm test:integration:postgres`)
 - Run migration-from-empty-database verification

4. **Configure isolated PostgreSQL for CI**:
 - Prefer reusing the existing Testcontainers-based integration infrastructure on the CI runner
 - Only configure a separate service container if implementation proves Testcontainers cannot run in the CI environment
 - Ensure database is ephemeral and isolated
 - Never use `finance_hub_prod`

5. **Configure environment variables**:
 - Set required environment variables for tests
 - Ensure no secrets are hardcoded
 - Use GitHub Secrets for any sensitive values if needed

6. **Set minimum repository permissions**:
 - Grant only `contents: read` unless another permission is demonstrably necessary

7. **Ensure reliable failure detection**:
 - Pipeline should fail on any step failure
 - Exit codes must be properly propagated

8. **Document CI usage**:
 - Add README section or separate doc explaining CI pipeline
 - Document how to run CI-equivalent checks locally

## Goal

## Implementation contract

- GetTransaction: lookup by UUID primary key; return full TransactionRecord including derived `is_refund` flag.
- ListTransactions: `book_id` is optional; finance:admin may list across Books when omitted and a supplied `book_id` filters exactly that Book. No per-Book authorization model is introduced. Search is a bounded M04 decision: case-insensitive matching over description, notes and source_reference. Filtering and pagination are stable, with default order `created_at DESC, id DESC`, page default 1, page_size default 50 and max 100.
- GetLastTransaction: `book_id` required; `status = posted` filter applied at DB level via partial index; `ORDER BY created_at DESC, id DESC LIMIT 1`; does NOT order by transaction_date.
- Supplied Book filters and references preserve integrity; Get-by-ID is authorized by finance:admin scope, not per-Book tenancy.
- Read repositories do not participate in write locking protocol.

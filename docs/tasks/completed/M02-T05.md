## Role responsibilities

| Role | Purpose | Grants |
| --- | --- | --- |
| finance_hub_migrations | Applies/reverts migrations | DDL on all tables; SELECT/INSERT/UPDATE/DELETE on migration tracking table |
| finance_hub_app | Runtime application access | SELECT/INSERT/UPDATE/DELETE on ordinary business tables; SELECT/INSERT only on Audit; no DDL or Audit UPDATE/DELETE/TRUNCATE |
| finance_hub_readonly | Analytics/reporting access | SELECT only on all business tables; no write access |

## Migration and rollback

No migration number consumed. Role bootstrap is separate from schema migrations. Scripts live in `packages/database/roles/` or similar dedicated directory. Canonical down/reapply is tested in disposable databases owned by the migrations role. Bootstrap deliberately has no destructive global-role teardown; container disposal removes test roles. Live role removal requires a separately authorized infrastructure task.

## Implementation Summary

### Dockerfile Architecture
4-stage multi-stage build:
1. **deps**: Installs all dependencies (including devDependencies) for build
2. **build**: Compiles TypeScript sources for all workspace packages
3. **prod-deps**: Installs only production dependencies via `pnpm install --frozen-lockfile --prod`
4. **runtime**: Minimal runtime image with production-only node_modules, built artifacts, non-root user

### Runtime Bootstrap Changes
Modified `apps/api/src/index.ts` to add:
- Configurable PORT (default 3000) and HOST (default 0.0.0.0) from environment
- SIGTERM/SIGINT signal handlers for graceful Fastify shutdown
- Startup error logging and exit code 1 on failure
- Preserved `buildApp()` factory pattern for testability

### Security Baseline
- Non-root user `appuser` (UID 999, GID 999)
- No secrets or credentials embedded in image layers
- Production-only dependencies (no TypeScript, ESLint, Vitest, etc.)
- HEALTHCHECK configured on `/health` endpoint (process liveness)

### Files Created/Modified
- `apps/api/Dockerfile` — new multi-stage Docker packaging
- `.dockerignore` — new build context exclusion rules
- `apps/api/src/index.ts` — minimal graceful shutdown bootstrap

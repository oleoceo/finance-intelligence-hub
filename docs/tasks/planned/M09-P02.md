**Status:** PLANNED. **Phase:** local/CI. **Dependencies:** accepted P01 and explicit task activation. **Authority:** `07-SECURITY.md`, `08-BACKUP-RESTORE.md`, `09-ROADMAP-TESTS.md`.

**Goal:** Define and test encrypted Restic snapshot flow and parametrized rclone transport, with recovery material external to the VPS.

**Allowed paths when activated:** `scripts/backup/**`, `infra/finance-backup/**` templates, `scripts/backup/tests/**`, M09 runbooks/task docs.

**Acceptance:** Backup uses a verified P01 artifact; repository init/snapshot/check and remote transfer have explicit failure states. Off-site contains Restic ciphertext only; no plaintext dump. Password, rclone credentials and recovery copy are injected externally and absent from logs/Git. Failed upload never reports completed off-site protection and preserves a recoverable local artifact. Recovery procedure explains independent possession of password/config outside VPS.

**Required tests:** Local Restic repository plus local/test rclone target, snapshot list/check/restore integrity, missing/wrong password, truncated artifact, simulated network/remote failure and retry, plaintext scan of off-site target, secret redaction. Real Google Drive is deferred.

**Excluded:** Real Drive connection, VPS repository init, live secrets, real backup, scheduler installation, Production restore.
